# bookstore-SQL-analysis
Bookstore sales and customer analysis using SQL and PostgreSQL.

Project Overview
This project analyzes a bookstore database using SQL and PostgreSQL to extract insights about books, customers, orders, sales, and inventory.

The database consists of three main tables:
Books – contains book details such as title, author, genre, price, publication year, and stock.
Customers – contains customer information including name, email, city, and country.
Orders – contains order details including customer, book, order date, quantity, and total amount.

Objectives
The project focuses on answering business-related questions such as:

Which books belong to a particular genre?
What is the total stock available?
Which book is the most expensive?
What is the total revenue generated?
Which books are ordered most frequently?
Which authors have the highest book sales?
Which customers have placed multiple orders?
Which customer has spent the most?
How much stock remains after fulfilling orders?
